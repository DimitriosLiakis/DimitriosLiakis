### 🔬 Featured project — Diploma thesis

**[Swin-UMamba + DyCON + LCC](https://github.com/DimitriosLiakis/swin-umamba-dycon-lcc)** — semi-supervised 3D medical image segmentation
- **Swin-UMamba** backbone: Mamba (State Space Model) blocks in a hierarchical U-shaped network, with ImageNet/VMamba-pretrained encoder.
- **DyCON** training: mean-teacher framework with uncertainty-aware consistency and feature-contrastive losses — extended with a teacher cross-negative branch and gambling-softmax uncertainty weighting.
- **LCC** post-processing: largest-connected-component filtering that removes false-positive islands (biggest single lever on PancreasCT: Dice 46 → 58, HD95 halved).
- Reaches **71 Dice with only 12 labeled volumes** — matching the fully-supervised 62-label baseline.
